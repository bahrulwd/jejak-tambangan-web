# Jejak Tambangan - Web Portal Kelurahan Tambangan

> **Portal Resmi & Profil Potensi Kelurahan Tambangan, Kecamatan Mijen, Kota Semarang**  
> Program Kerja Digitalisasi Desa & Dokumentasi Sejarah Budaya — **KKN UNNES GIAT 17 Kelurahan Tambangan**.

---

## 📌 Sekilas Proyek

Portal web ini dikembangkan sebagai sarana informasi publik, arsip sejarah lisan, dan promosi potensi lokal Kelurahan Tambangan (Kecamatan Mijen, Kota Semarang). Melalui pendekatan *Hybrid Modern-Institutional*, platform ini menyajikan:

- **Toponimi & Falsafah Sejarah**: Rekaman sejarah lisan penuturan sesepuh Mbah Ngadi mengenai jejak Sunan Kalijaga di Jati Ombo & Sungai Bonijo, asal-usul nama Tambangan dari seutas tali tambang penarik kayu jati, serta tradisi sakral Nyadran di bulan Rajab.
- **Arsip Yuridis & Transformasi Wilayah**: Dokumentasi formal integrasi yurisdiksi dari Kabupaten Kendal ke Kota Semarang (PP 16/1976) dan pemekaran Kelurahan Tambangan (PP 50/1992).
- **Film Dokumenter Resmi**: *Jejak Tambangan* (Durasi: 09:48) karya kolaborasi Dewi Ananda Agustin & Muhammad Bahrul Widad.
- **Pemetaan Potensi Unggulan**: Profil Kampung Wisata Sawah, kuliner khas Soto Sawah Mbak Tutik, Budaya Membatik, Budidaya Anggrek, dan Kesenian Langka Laes.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom Design System
- **Animation**: Framer Motion
- **Icons**: Google Material Symbols Outlined
- **Routing**: React Router v6

---

## 🚀 Panduan Memulai (Local Development)

### 1. Masuk ke direktori frontend
```bash
cd frontend
```

### 2. Install dependensi
```bash
npm install
```

### 3. Jalankan server pengembang
```bash
npm run dev
```

### 4. Build untuk produksi
```bash
npm run build
```
